用語解説

微小推力測定シミュレータで使う用語、計算式、値の例をまとめています。

ブラックボックスにせず、途中の考え方も見えるようにします。

用語の意味だけでなく、「どの値を入れて、どの式で計算し、画面のどこに出るのか」まで追えるページを目指します。

見せる内容を分けて表示します

シミュレータでは、結果だけを出すのではなく、根拠が追えるようにします。初めて見る方でも「なぜその値になるのか」を確認できる構成にします。

  • 入力値：材質、ワイヤー径、ファイバー長、慣性、減衰、光学距離、入力トルクなど
  • 計算式：k=πGd⁴/(32L)、θeq=τ/k、x≒2Lθ など
  • 途中値：剛性k、捩れ角θ、光点変位x、S/N比など
  • 結果：検出可能／条件付き評価／検出不可といった判定と、その理由を文章で表示します

計算例も一緒に見せます

値の大きさが想像しやすいように、代表的な数値を入れた例を載せます。

τ = 2.0×10⁻⁹ N·m
k = 2.0×10⁻⁶ N·m/rad
θeq = τ / k = 1.0×10⁻³ rad

このように、式・単位・換算後の値を並べると、シミュレータの結果がただの数字ではなくなります。

シミュレータで使う基本式

用語の意味だけでなく、画面上の値がどの入力値と式から出ているかも確認できるようにしています。

剛性kの逆算

k = πGd⁴ / (32L)

ワイヤーは、太いほど・短いほど硬く(kが大きく)なります。Gは材質ごとに決まった硬さの指標(せん断弾性率)です。

  • G：材質のせん断弾性率(タングステン160GPa、石英30GPa、ナイロン1.1GPa)
  • d：ワイヤー径 m、L：ファイバー長 m
  • 例：d=0.1mm、L=0.785m、タングステンならk≒2.0×10⁻⁶ N·m/rad

ねじれの釣り合い

θeq = τ / k

推力(トルクτ)がアームを押すと、ワイヤーが戻ろうとする力と釣り合うところで止まります。その角度がθeqです。

  • τ：入力トルク N·m、k：剛性 N·m/rad、θeq：平衡角 rad
  • kが小さいほど、同じτでも大きく捩れます(装置が敏感になる)

ねじり系の動き

Iθ'' + cθ' + kθ = τ外力 + τノイズ

シミュレータの動きの中心になる式です。慣性、減衰、ねじれの戻り、外力、ノイズをまとめて扱います。

  • I：慣性モーメント kg·m²、c：減衰係数 N·m·s/rad
  • cを大きくすると、揺れが早く収まります(overdamped)

ミラー反射と光点変位

x ≒ 2Lθ

ミラーが少し傾くと、反射した光は約2倍の角度で動きます。Lが長いほど、光点の動きは大きく見えます。

  • 例：L=1m、θ=1.0×10⁻³ radなら、x≒2mmです。
  • シミュレータでは、光学表示の光点位置に対応します。

S/N比

S/N比 = 信号 / ノイズ

信号がノイズからどれくらい見分けやすいかを示します。値が大きいほど、はっきり検出できます。

  • 例：信号1.0×10⁻³ rad、ノイズ2.0×10⁻⁴ radなら、S/N比は5です。
  • シミュレータでは、検出可能／条件付き評価などの判定根拠になります。

渦電流ダンパーの減衰

c = I × λ、λ ∝ B² / ρ

磁石とパドルの距離(ギャップ)を近づけるほど磁場Bが強くなり、減衰cが大きくなります。実物の可変式ダンパーと同じ理屈です。

  • B：磁場 T(テスラ)、ρ：パドル材質(アルミ)の電気抵抗率
  • 装置3Dページでギャップを動かすと、その場でcを再計算します。

用語一覧

シミュレータ内で出てくる言葉を、平易な説明と値の例でまとめています。

01仮想トーションバランス

細いワイヤーのねじれを使って、小さな力(推力)を調べる架空の装置です。力が加わると、アームとミラーが少しだけ回ります。

値の例：ファイバー長0.785m・ワイヤー径0.1mm(タングステン)のとき、剛性kは約2.0×10⁻⁶ N·m/radです。

02剛性 k

ワイヤーがどれだけ捩れにくいかを表す値です。単位はN·m/rad(ニュートンメートル毎ラジアン)。値が大きいほど、同じ力でも捩れる角度が小さくなります。

値の例：材質をタングステンからナイロンに変えると、kはおよそ1/145になります(ワイヤーが柔らかくなる分、同じ力でも大きく捩れます)。

関連：k = πGd⁴/(32L)

03減衰 c

揺れがどれだけ早く収まるかを表す値です。単位はN·m·s/rad。cが大きいと振動せずにじわっと収まり(overdamped)、小さいとしばらく揺れ続けます。

値の例：c=1.0×10⁻⁵ N·m·s/radが標準設定です。渦電流ダンパーの磁石ギャップを狭めるとcは大きくなります。

04慣性 I

物体の回りにくさを表す値です。単位はkg·m²(キログラムメートル毎乗)。値が大きいほど、力を加えてもゆっくりとしか動きません。

値の例：I=1.0×10⁻⁶ kg·m²が標準設定です。アーム両端の錘の重さと配置で決まります。

05捩れ角 θ と光点変位 x

θはワイヤーが捩れた角度(単位rad=ラジアン)。xは、その捩れをミラーで光学的に拡大して読み取った、光点の動いた距離(単位mm)です。

値の例：光学距離L=1mのとき、θ=1.0×10⁻³ radならx≒2mmです。

関連：x ≒ 2Lθ

06S/N比

信号(測りたい変化)とノイズ(余分なゆれ)の比です。大きいほど、信号がはっきり見分けられます。

値の例：S/N比が10を超えると「検出可能」、小さいと「条件付き評価」や「検出不可」と判定されます。

07材質(タングステン・石英・ナイロン)

ワイヤーの材質です。材質によって硬さ(せん断弾性率G)と、温度による硬さの変わりやすさ(温度係数)が異なります。

値の例：G=160GPa(タングステン)、30GPa(石英)、1.1GPa(ナイロン)。石英はタングステンと温度係数の符号が逆になる、という実例が文献にあります。

08ノイズ成分(White・drift・periodic・impulse・optical・numeric)

装置に必ず混ざる6種類の揺らぎです。それぞれ熱雑音、温度ドリフト、地面の傾き、突発的な衝撃、光学読取誤差、量子化誤差という別々の原因を持ちます。

値の例：各成分は個別にON/OFF・強度を調整でき、観測結果のS/N比に影響します。

09遮蔽レベル(弱・標準・強)

装置を振動・温度変化から守る対策の強さです。防振ゴムや断熱材を積み増すイメージで、レベルを上げるほど一部のノイズが減ります。

値の例：drift成分は標準で約1/10、強で約1/33まで減ります。ただしWhite・periodicは原理的に遮蔽の効果を受けません。

10渦電流ダンパーとギャップ

磁石とアルミ板(パドル)の間に生じる電磁的なブレーキで、揺れを減衰させる仕組みです。ギャップ(隙間)を狭めるほど効きが強くなります。

値の例：基準ギャップ8mmで磁場0.15T。ギャップを4mmまで狭めると磁場は0.6Tまで強くなります。

11被検証推力源(τ)

アーム端に搭載する、検証したい推力の発生源です。未確認推力のような未確認の推力主張も、この位置に置かれたものとして扱われます。

値の例：装置3Dページでは橙色のラベル「τ 被検証推力源」で示されます。

12AUTO(観測方式)・校正モード

AUTOは、選んだモードに応じてシミュレータが推奨観測時間を自動で設定する方式です。校正モードは、既知の入力トルクを使って、装置が正しく検出できているかを確かめるためのモードです。

値の例：校正モードのAUTO推奨時間は120秒です。

このページについて

ここに載っている数式・数値は、シミュレータ本体および装置3Dページの実装と同じものです。値を変えると、この用語解説で示した通りの関係で結果が変化します。詳しい操作方法は操作マニュアル、装置の全体像は実験の解説をご覧ください。
