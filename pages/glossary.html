用語解説

シミュレータで使う用語、計算式、値の例をまとめています。

ブラックボックスにせず、途中の考え方も見えるようにします。

用語の意味だけでなく、「どの値を入れて、どの式で計算し、画面のどこに出るのか」まで追えるページを目指します。

見せる内容を分けて表示します

シミュレータでは、結果だけを出すのではなく、根拠が追えるようにします。初めて見る方でも「なぜその値になるのか」を確認できる構成にします。

  • 入力値：アーム長、ねじり剛性、観測距離、ノイズ量など
  • 計算式：τ = κθ、F = τ / r、x ≒ 2Lθ など
  • 途中値：トルク、ねじれ角、光点変位、平均値、S/N比など
  • 結果：推力の目安、判定理由、注意点を文章で表示します

計算例も一緒に見せます

値の大きさが想像しやすいように、代表的な数値を入れた例を載せます。

τ = 1.0×10⁻⁸ N·m
r = 0.10 m
F = τ / r = 1.0×10⁻⁷ N = 0.1 μN

このように、式・単位・換算後の値を並べると、シミュレータの結果がただの数字ではなくなります。

シミュレータで使う基本式

用語の意味だけでなく、画面上の値がどの入力値と式から出ているかも確認できるようにしています。

ねじれとトルク

τ = κθ

線がねじれると、元に戻ろうとする力の効果が出ます。θが角度、κがねじれにくさ、τが回す力です。

  • θ：ねじれ角 rad
  • κ：ねじり剛性 N·m/rad
  • τ：トルク N·m
  • シミュレータでは、角度からトルクを推定する根拠になります。

推力とトルク

F = τ / r

力がアームの端にかかると、中心を回すトルクになります。rは中心から力がかかる位置までの距離です。

  • 例：τ = 1.0×10⁻⁸ N·m、r = 0.10 mなら、F = 1.0×10⁻⁷ Nです。
  • 1.0×10⁻⁷ N = 0.1 μNです。
  • シミュレータでは、トルク表示を推力表示へ変換する場所です。

ねじれ振り子の動き

Iθ'' + cθ' + κθ = τ外力 + τノイズ

シミュレータの動きの中心になる式です。慣性、減衰、ねじれの戻り、外力、ノイズをまとめて扱います。

  • I：回りにくさを表す慣性モーメント
  • c：減衰の強さ
  • τ外力：調べたい推力などによるトルク
  • シミュレータでは、波形のゆれ方や落ち着き方の説明になります。

レーザー反射と光点変位

x ≒ 2Lθ

鏡が少し傾くと、反射した光は約2倍の角度で動きます。Lが長いほど、光点の動きは大きく見えます。

  • 例：L = 1 m、θ = 0.001 radなら、x ≒ 2 mmです。
  • 小さな角度を見やすくするための重要な式です。
  • シミュレータでは、光点表示の移動量に対応します。

平均値とS/N比

平均値 = データの合計 / データ数
S/N比 = 信号 / ノイズ

平均値はばらつきをならすために使います。S/N比は、信号がノイズからどれくらい見分けやすいかを示します。

  • 例：信号1.0 μN、ノイズ0.2 μNなら、S/N比は5です。
  • 値が大きいほど、信号として見やすくなります。
  • シミュレータでは、判定理由の説明に使います。

用語一覧

各シミュレータ内で出てくる言葉を、平易な説明と値の例でまとめています。

01トーションバランス

細い線のねじれを使って、小さな力を調べる装置です。力が加わると、棒や鏡が少しだけ回ります。

値の例：角度が0.001度だけ動くような変化も、レーザーを使うと見やすくできます。

関連：τ = κθ で、ねじれ角からトルクを見積もります。

02ねじれ振り子

線がねじれて戻ろうとすることで、ゆっくり行ったり来たりする動きです。

値の例：1往復に30秒かかる場合もあれば、数分かかる場合もあります。装置の重さや線の硬さで変わります。

03レーザー反射

レーザーの光を鏡に当てて、わずかな角度の変化を大きく見やすくする方法です。

値の例：鏡が0.001 rad傾き、壁まで1 mあると、光点は約2 mm動きます。

関連：x ≒ 2Lθ を使います。

04光点変位

反射した光の点が、画面や壁の上でどれだけ動いたかを表す言葉です。

値の例：光点が中心から+3 mm動いた、という形で記録します。

05ノイズ

測りたい信号にまざる、余分なゆれやばらつきです。風、床の振動、温度変化などでも増えます。

値の例：本当の信号が1.0 μNでも、ノイズが±0.5 μNあると判断が難しくなります。

06平均値

いくつかの値をならして見た、代表的な値です。ばらつきがあるデータを見るときに使います。

値の例：0.9、1.1、1.0 μNなら、平均値は約1.0 μNです。

07S/N比

信号とノイズの比です。信号がノイズよりどれだけ見分けやすいかを表します。

値の例：信号1.0 μN、ノイズ0.2 μNなら、S/N比は5です。大きいほど見分けやすいです。

関連：S/N比 = 信号 / ノイズ です。

08外力

外から加わる力のことです。実験では、調べたい推力や、風などの余分な力も外力になります。

値の例：Force ONの間だけ+1.0 μNを加え、OFFで0に戻す、という形で比べます。

09減衰

ゆれや動きが、だんだん小さくなっていくことです。空気抵抗や内部の摩擦で起こります。

値の例：最初のゆれが10 mm、次に6 mm、次に3 mmのように小さくなります。

10剛性

どれだけ変形しにくいかを表す性質です。ねじれにくい線ほど剛性が高いと言えます。

値の例：剛性が高いと同じ力でも角度は小さくなります。剛性が低いと大きく動きます。

11観測時間

測定や観察を続ける時間のことです。短すぎると、ゆれと信号の区別が難しくなります。

値の例：まず5分、次に15分、必要なら30分のように長くして比べます。

12キャリブレーション

測定のずれを調整して、正しく測れるようにすることです。測定前の基準合わせです。

値の例：既知の1.0 μN相当の力を入れて、表示も1.0 μNに近づくように合わせます。

13Cavendish実験

重力を確かめるために行われた有名な実験です。小さな重力を、ねじれの動きとして観測します。

値の例：万有引力定数Gは約6.67×10⁻¹¹です。とても小さいため、精密な測定が必要です。

関連：F = G m₁ m₂ / r² を使います。
